# 启动台浮窗 · 本地版（零登录）

把启动台变成浏览器里的小窗口：**任何网页**右下角有一个 ⚡ 悬浮球，点开就是启动台——今日待办、一键启动、打卡、进度、备忘。

**数据只存在你自己浏览器里，不需要登录任何平台，不联网也能用。**

提供两种形态，功能完全一致：

| 形态 | 适合谁 | 安装成本 |
|---|---|---|
| **油猴脚本**（`启动台浮窗.user.js`） | 大多数人，跨浏览器通用 | 装个脚本管理器，点一下安装链接 |
| **Chrome/Edge 扩展**（`extension/`） | 不想装管理器、想像 Video Together 那样「下载后自主安装」 | 下载文件夹 → 开发者模式加载已解压扩展 |

Metro 扁平化风格（Azure 蓝 #00BCF2），与看板本体一致。

---

## 一、功能

- **悬浮球 / 小窗**：任何网页右下角 ⚡ 点击展开；拖标题栏移动，拖右下角把手缩放
- **宽窄双形态**：「宽窄」按钮或双击标题栏切换（窄 400×580 / 宽 760×640）
- **今日待办**：按「逾期 → 今天该启动 → 还没到点 → 已完成」排序；逾期红条 + 「已顺延 N 天」，昨天没打卡自动滚入不消失
- **一键启动**：视频类直接开链接；本地应用一键下载专属 `.bat` 启动器（双击即开，可固定桌面）
- **打卡**：一键打卡/取消，连续天数实时算
- **本周进度**：每个入口的本周打卡（x/目标）+ 连续天数 + 7 天柱状图
- **每日备忘**：自动保存，显示最近 5 天历史
- **添加/编辑入口**：名称、类型（视频/本地应用）、链接或路径、提醒时间、每周目标、备注、启用开关
- **数据管理**：导出备份 JSON / 导入恢复 / 载入示例 / 清空
- **快捷键**：`Alt+L` 唤出收起，`Esc` 收起/关弹层
- **状态记忆**：位置、大小、宽窄、展开状态自动保存，下次原样恢复

## 二、安装

### 方式 A：油猴脚本（推荐）

1. 先装一个脚本管理器（任选其一）：
   - [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox）
   - [Violentmonkey](https://violentmonkey.github.io/)（开源，Edge/Chrome/Firefox）
2. 点安装链接：

   ```
   https://raw.githubusercontent.com/Casmeter/launchpad-widget/main/启动台浮窗.user.js
   ```

   Tampermonkey 会弹出安装页，点「安装」。
3. 打开任意网页，右下角出现 ⚡ 即可用。

### 方式 B：浏览器扩展（Video Together 式安装）

1. 下载本仓库的 `extension` 文件夹（或整个仓库 zip，解压）
2. Edge：地址栏输入 `edge://extensions` → 打开左下角「开发人员模式」→ 点「加载解压的扩展」→ 选择 `extension` 文件夹
   Chrome：`chrome://extensions` → 右上角「开发者模式」→ 「加载已解压的扩展程序」
3. 打开任意网页即生效（file:// 本地文件需在扩展详情里打开「允许访问文件网址」）

> 扩展未签名、仅本机加载；只申请了 `storage` 一个权限（存你的看板数据）。

### 装了不显示窗口？按这个顺序查

1. **页面刷新了吗**——装脚本前就已打开的页面不会注入，按 `F5` 刷新
2. **脚本启用了吗**——Tampermonkey 图标 →「管理面板」，确认「启动台浮窗」开关是绿的
3. **打开的是 http/https 网页吗**——脚本不注入 `edge://` 起始页、浏览器内置页面、应用商店页。随便开个百度/微博就能看到
4. **按 `Alt+L`**——这是唤出快捷键，能拉起说明脚本在工作
5. **Tambermonkey 图标显示数字 1+**——说明脚本已在该页运行；右键图标 →「查看脚本报告」有报错就是页面 CSP 拦截
6. **换「启动台浮窗.exe」**——如果浏览器侧怎么都别扭，用上一级目录的 exe（Edge App 窗口 + 本地页面，完全不依赖脚本管理器，双击即用）

## 三、数据存在哪 / 会不会丢

| 形态 | 存储位置 | 跨站共享 | 换设备 |
|---|---|---|---|
| 油猴脚本 | 脚本管理器自带的 GM 存储 | ✅ 同一浏览器所有网站共享一份 | ❌ 跟随脚本管理器导出 |
| 扩展 | `chrome.storage.sync` | ✅ | ✅ 登录同一浏览器账号可同步 |

**重要提醒**：

1. 数据在浏览器本地，**清浏览器缓存/卸载脚本/重置设置会丢数据**——请定期用面板里的「导出备份」下载 JSON
2. 换电脑：旧电脑「导出备份」→ 新电脑装好后「导入恢复」
3. 想多设备实时同步：把导出的 JSON 放到网盘，或者用支持云同步的密码管理器式方案自行同步 `storage` 数据

## 四、从旧版（WorkBuddy 云端看板）迁移数据

如果你之前用过 WorkBuddy 看板且里面有数据：

1. 打开旧看板 → 设置 → **导出备份**，得到一个 JSON（里面是 `rows` 数组，中文字段名）
2. 打开本浮窗 → 「导入恢复」→ 选那个 JSON
3. 入口、打卡记录、备注会自动转换导入（备忘行会被忽略，本地版备忘按日期单独存）

导入是**合并**的：id 相同的条目覆盖，不同的追加，不会丢你浮窗里已有的数据。

## 八、三种形态怎么选

- **本脚本/扩展（本地版）**：零登录、任何网页唤出、数据在浏览器——日常首选
- **`启动台浮窗.exe`**（上一级目录，v2.0 本地零登录版）：Edge App 窗口 + 内嵌本地页面，系统级置顶、托盘常驻、开机自启，脱离脚本管理器，双击即用
- **WorkBuddy 看板网页**：需要多设备云同步时用（数据在资料库）
